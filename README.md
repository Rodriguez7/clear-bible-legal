# Clear Bible public support

Static support pages for Clear Bible, operated by Rise (Kayembe Mukala).

Contact: support@syncher.online. No application source, account data, tracking scripts or credentials are included.

support.html and imprint.html are live. terms.html explains and links the standard Apple EULA already selected for Clear Bible on iOS; it does not adopt a custom agreement.

privacy-review.html and terms-review.html are explicitly review copies, not effective policies. There is no effective privacy.html yet; draft URLs are not supplied as App Store policy URLs.
