Cloud permission wording

The operator chose separate, optional permission before personal cloud uploads. These ten new English phrases are currently identical English fallbacks in German, Brazilian Portuguese, Spanish and French. On October 14, 2026, the user confirmed human review completed and approved these exact words as-is, including the English fallbacks. Earlier reviewed text is unchanged.

  1. Cloud storage
  2. Notes, AI answers and reading or lesson progress can reveal religious beliefs. Allow Clear Bible to store them in Convex for sync?
  3. Optional. Reading and live AI stay available. Turning this off stops future uploads; existing cloud data stays until you delete your account. AI sharing is separate.
  4. Allow cloud storage
  5. Keep reading locally
  6. Stop cloud storage
  7. Cloud storage is allowed for this account.
  8. Cloud storage is off for this account.
  9. Cloud permission could not be confirmed. Try again.
  10. Uploads are paused on this device. Connect to finish turning cloud storage off.

The screen appears from Privacy → Cloud storage, or when Sync needs permission. Sign-in and AI sharing do not automatically grant cloud storage. Closing or continuing to local reading does not grant it. Turning storage off pauses future uploads on this device and sends a server withdrawal; an offline withdrawal remains queued. Previously stored data is not erased by the switch. Questions are not currently saved as chat history; AI answer caches require storage permission, while live AI has its own sharing permission.

Approval covers these exact words and their context; later wording changes need a new review. This is a local implementation, not an updated TestFlight or effective privacy policy. Prepared October 14, 2026.
